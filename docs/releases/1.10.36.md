# 1.10.36

Swofty Launcher for F1 25 1.10.36 lets the Steam and EA app copies of one F1 25 version share a session, warns when an addon set makes HUD customisation close the game, and adds championship standings and more broadcast live data to the standard library.

## Fixes

- A shared session takes the Steam and EA app copies of one F1 25 version as the same game. The two copies' `F1_25.exe` files differ, so a player on one store was told their F1 25 was another version than the host's on the other. The launcher now compares the game's file version, and goes by the exe only when it cannot read the version.
- A build warns when the addons on one HUD part make the Track Position list too big for HUD customisation (OSD Customization in the pause menu), where the game closes when it opens. The warning names the addons and the ones to turn off, races show the HUD as before, and it is in the build log and `conflicts.json`. See [HUD screens](/reference/ops/hud-screens).
- An addon's overlay no longer disappears for a frame outside the part it draws last when that part is clipped. A tower no longer drops out while a card or flag animates in beside it.

## Standard library

- **Championship standings.** `swofty/standings.hpp` reads the loaded career's drivers' and constructors' championships with each row's wins, podiums and points per round, and where the season is, from any thread. See [Championship standings](/reference/std/championship).
- **Broadcast live data.**
  - `live::driver_identity` gives a car's driver code, first and last name in the game's language. See [Driver names](/reference/std/live#driver-names).
  - Each car's pit stop time and safety car delta.
  - The `session.start_reaction` event gives each car's reaction time after lights out and whether it jumped the start. See [Race control messages](/reference/std/race-control#race-control-messages).
- **Bindings.** The stock screen waterdrop emission rate.

## Docs

- [Windows](/guide/windows) names the **F1_25.exe - Bad Image** message with error status `0xc0e90002`, which Smart App Control shows when it blocks a Swofty file.
