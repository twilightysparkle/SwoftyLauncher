# 1.8.34

Swofty Launcher for F1 25 1.8.34 fixes a track select crash with season addons of more than 20 cars, and the frame and session clock of the telemetry feed for addons.

## In game

- A season addon with more than 20 cars that doesn't name its own entrant list now copies the game's 2025 list, like every other season. Copying the 2026 list made Grand Prix and Time Trial track select crash as soon as that season was picked.

## For addon authors

- `content.package`: a package of more than 20 seats without `entrant_list_from` or `standings_from` copies `f1_2025` and `f1_teams_2024`, then adds its extra rows ([career](/std/systems/career#a-box-with-12-teams)).
- `telemetry` (experimental): the feed's `frame` and `session.session_time` advance again on the current Steam build. The core drives them from the same frame tick and session start hooks as `swofty/events.hpp` instead of separate signatures, which could match nothing ([telemetry](/reference/std/telemetry)).
