# 1.8.20

Swofty Launcher for F1 25 1.8.20 fixes a restart prompt that could close without doing anything.

## Launcher

- Confirming the **Restart F1 25?** prompt now closes F1 25 and carries on. Before, the prompt could close and leave the game running.
- Other small fixes.
