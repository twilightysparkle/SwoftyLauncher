# 1.10.37

Swofty Launcher for F1 25 1.10.37 restarts the game when the EA app updates it at launch, keeps your save backups from before a race the game keeps reloading, and lets tracks with large collision and AI marker tables load.

## Fixes

- When the EA app installs an F1 25 update as Play starts the game, the game no longer starts on the update's stock files with addons built for the version before. The launcher closes the game before it reads its database, builds the profile for the new version and starts the game again.
- A career save whose finished race the game keeps reloading (a loading screen that never ends) no longer pushes the older saves out of the save backups. From the third reload in a row, no new backup is written until the game restarts, so a backup from before the race stays to restore. A normal session load writes backups again. `loader.log` says when this happens.
- When the addons on one HUD part make the Track Position list too big, the refusal and the HUD customisation warning no longer tell you to turn off an addon that another addon you have on needs, such as SWOFTY 2010 and SWOFTY 2011 for Progressive Career. They name the addons you can turn off. See [HUD screens](/reference/ops/hud-screens).
- A track with more than about 1,640 collision tiles no longer loses its last tiles, where cars fell through the ground. The core raises the game's world-1 large-geom pool from 2,000 to 8,192 objects. `SWOFTY_COLLISION_GEOM_POOL=<n>` sets the size (at most 9,728), and `0` or `off` turns it off.
- A track whose AI lane has more than 256 markers on one channel no longer crashes while it loads. A 25 km Nordschleife needs about 548 width-class markers. `SWOFTY_AI_MARKER_CAP_GUARD=0` turns the guard off.

## Standard library

- **Team logos.** `team.logo.resolve` fires on the Choose Driver grid cards (`site_Game_DriverSelect_BadgeFormat`) and on the broadcast grid rundown cards before a race (`site_Game_GridRundown_TeamLogoBind`, experimental, in-game check pending).
- **Box assets.** `content.box_assets` 1.1 adds `kind: scene`: a box's archive is read first by the stock scene asset groups (`cinematicsgrid`, `garagecrew`) in that box's sessions.
