# 1.10.32

Swofty Launcher for F1 25 1.10.32 brings back the tyres of the last cars in a 26-car grid, lets addons lay out the car setup screen and offers the Max fuel mix in races when an addon unlocks it.

## Fixes

- In a 26-car grid the last two cars, the player's car in Grand Prix among them, have their tyres again. The game updated only the first 27 entries of its tyre list, and the cars past them never got their tyres placed.

## Features

- The MFD fuel mix offers **Max** in race sessions when an addon unlocks Max. Before, the game offered it only outside races.

## Addon API

- `setup.layout` is a new experimental registry ([Setup layout](/reference/std/setup-layout)). A record gives the setup screen of one scope its own sliders, order, section headers, names, units, ranges and step counts, and its own value text: `format`, `decimals`, `group`, `labels` and `range_text`.
- `car.setup.applied` is version 2. It carries the step of every slider in the setup the game applied (`steps`, `step()` in `swofty/systems/cars.hpp`), from the setup screen and from the pre-race setup alike.

## Under the hood

- The tyre list fix updates the tyre system entries past the caller's vehicle count after the last one it updates. `loader.log` lines start with `[tyres] list fix`. `SWOFTY_TYRE_LIST_FIX=0` turns it off, and `SWOFTY_TYRE_UPDATE_COUNT=0` turns off the update counts.

- Updated the offline play module to 0.4.0.
