# 1.8.32

Swofty Launcher for F1 25 1.8.32 downloads its updates from Swofty's own server instead of GitHub.

## Updates

- The launcher, `swofty update` and the installer read the latest version from `cdn.swofty.net` and download it from there, checking every file's SHA-256. When the CDN can't be reached, they fall back to GitHub as before, and a download that fails from the CDN is retried once from GitHub.
- The installer download links on this site now point at `cdn.swofty.net` ([updating](/using/updating)).
