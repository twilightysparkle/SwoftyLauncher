# 1.8.12

Swofty Launcher for F1 25 1.8.12 adds a Downloads page for addon installs and updates, a Settings page that shows what the launcher keeps on disk, and each installed addon's changelog on the Addons page. In game, ADDON SETTINGS gets proper icons, one tile per track addon and a row per folder. Building and restoring a large profile is faster.

## Addon Browser and Addons

- **Downloads page.** Installs, updates and **Update All** from the Addon Browser go into a queue on the new **Downloads** page, with progress, history for the session, retry and queue controls. You can keep browsing while downloads run, and choose how many run at once (1 to 10, 2 by default). Dependencies are checked again just before an addon installs, and each job installs into the profile it was started from. A failed install still shows a message wherever you are. The queue lasts until you close the launcher, which warns you if downloads are still waiting.
- **Changelogs.** Clicking an installed addon on the **Addons** page shows its changelog under "From the Addon Browser": every newer version tagged **New**, then your installed version, with older versions behind "Show N older versions".
- Addon settings in a narrow panel no longer draw their controls over the labels; controls wrap below their labels when there isn't room.

## Settings

- A new **Settings** page at the bottom of the sidebar shows your data folder, its total size and the free space on its drive, what takes the most room, and how to move the folder to another drive.
- **Clear old** removes old session logs after you confirm. It keeps the newest 20 and anything from the last 2 days, and never runs while F1 25 is open.
- **Clear old logs automatically** does the same at each launcher start. It's **off** unless you turn it on, so updating never deletes logs.
- **Play** and the Settings page warn you when the game's drive is getting too full for F1 25 to start, or when the drive with the data folder is too full to install or build addons.

## In game

- **ADDON SETTINGS** tiles show real icons: SwoftyMod, Simplified for Swofty, track addons and everything else each get their own.
- A track addon no longer shows twice on ADDON SETTINGS: its tile and page carry its track.
- ADDON SETTINGS lists a row for each folder on the launcher's **Addons** page, in the same order and under the folder's name, and long names are shortened to fit.
- SwoftyMod has a new setting, **Split the season picker** (on by default). Turn it off to keep the Grand Prix and Time Trial season picker on a single row.

## Performance

- Building a profile with many addons checks each source file once per build instead of repeatedly, and cleanup and restore reuse the file hashes the launcher already keeps, so pressing **Play** and restoring the game are faster on large profiles. A file you edited yourself is still never removed.
