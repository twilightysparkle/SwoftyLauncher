# 1.8.26

Swofty Launcher for F1 25 1.8.26 brings back the Addon Browser's original category boxes.

## Addon Browser

- **All addons** opens on the full-size category boxes again: each category with its icon, a few of its addons' icons, its name and how many addons it has. The category rows sit beneath them and still drag sideways.
- Select a box to see that category's addons. Select **Categories** (or **All**) to go back to the boxes and rows.
