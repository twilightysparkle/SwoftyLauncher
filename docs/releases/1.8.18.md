# 1.8.18

Swofty Launcher for F1 25 1.8.18 extends the check from 1.8.17 to track addons. A saved Grand Prix or career that raced a track whose addon is now off or uninstalled crashed the game while the session loaded.

## Careers and saves

- After each session the launcher now also records the track addons that session raced, on each career or saved Grand Prix season saved in it. A track addon a career never raced is not recorded, so turning off an unrelated track asks nothing.
- When one of those track addons is off or uninstalled, **Play** asks first and names the track addon and the careers. Turn it back on, or start a new Grand Prix instead of continuing the saved one. **Play anyway** still starts the game.
- The launch log line for a track the game can't find now says that its track addon is off or not installed.
