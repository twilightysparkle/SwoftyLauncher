# 1.8.25

Swofty Launcher for F1 25 1.8.25 draws addon overlays with Frame Generation on, stops a start-up crash with many season addons on, and gives addon authors Time Trial only and Grand Prix only era picker boxes.

## In game

- Addon overlays such as Spool Up, Race Broadcast and the Terminal Damage panel now draw when Frame Generation is on in F1 25's graphics settings. Before, they were hidden while Frame Generation was on. To turn this off, set `SWOFTY_OVERLAY_FG=0`, or `"overlay_fg": false` in `swofty/assets.json`.

## Play

- With a lot of season addons on at once, the game no longer crashes while it loads the grids at start. The launcher now reuses team and car numbers that no installed addon or saved career uses, keeps every number in the range the game can hold, and never gives two addons the same one.
- If some teams or cars still don't fit, the launcher leaves them out, along with the grids that use them, and Play says how many and from which addons. Turn some season addons off to get them back.
- Season addons that each add their own images to the same game folder no longer count as overlapping each other. Two addons that add a file with the same name still do.

## For addon authors

- An era picker box can be Time Trial only or Grand Prix only: set `only` on the native box (`swofty::era::Box::only`, era API 3) or `"only": "time_trial"` or `"only": "grand_prix"` on an `era.box` record (registry 1.2). Without it, a box shows in both pickers as before. On an older launcher, a native box with `only` set is refused rather than shown in both pickers ([era picker](/reference/std/era-picker)).
