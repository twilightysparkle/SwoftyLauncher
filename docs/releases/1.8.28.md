# 1.8.28

Swofty Launcher for F1 25 1.8.28 lets addons set a car's fuel mix.

## For addon authors

- `cars::live::set_fuel_mix(car_index, FuelMix)` switches a car to Lean, Standard, Rich or Max, the same way the MFD does. It only switches to a mix the car's MFD offers, and it runs on the game's flow thread (an event handler); elsewhere it answers `late`. On an older launcher it answers `unavailable`; check `cars::live::set_fuel_mix_available()` first. C: `SwoftyCarOps` version 4 adds `set_fuel_mix` ([car physics](/std/systems/car-physics)).
