# 1.8.24

Swofty Launcher for F1 25 1.8.24 makes load order problems one click to fix, fixes team select logos when several season addons are on, and warns about older careers that need addons that are off.

## Load order

- An addon in the wrong place now has a warning triangle by its name. Hover it to see why.
- One large **Fix load order** button at the top fixes every order problem at once, in place of the boxes in the addon list.
- The fix now takes folders into account, so the problem no longer comes back after the launcher reloads. If a folder would undo the fix, the addon is moved out of that folder and a message says which.
- When two addons each need the other loaded first, no order works: the bar names them and offers to turn one off.
- Built In addons such as Simplified for Swofty never raise a load order problem, and an addon below Simplified for Swofty now wins when both change the same thing, even when its change waits for rows another addon adds.
- Two addons that change the same thing show a quiet **Overlaps** badge instead of a warning.

## Team select logos

- Teams that borrow another team's logo now show the right one when other season addons are on too. Before, every team could show the same logo, such as Caterham or McLaren.

## Play

- Careers made before the launcher recorded their addons are now checked too: when a career's teams, cars or drivers come from an addon that is off or no longer installed, Play warns and names the careers. Turn the addons on, or restore an older save in **Profiles > Saves**.

## Translations

- More of the launcher's text can be translated, and counts such as "1 addon" and "3 addons" read correctly in every language.
