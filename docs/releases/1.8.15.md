# 1.8.15

Swofty Launcher for F1 25 1.8.15 fixes a crash while a Grand Prix or Time Trial loads, when the season addons in a profile together add more car packages than the game can number.

## Seasons and cars

- The game numbers car packages from 0 to 254. When the addons in a profile have already used every number, a car package an addon adds without a number of its own is now left out, and that addon's cars use the package they're based on. Before, the package was numbered past 254 and the session crashed while it loaded.
- The launch log names each package that's left out and the cars that use their base package instead.
