# 1.10.30

Swofty Launcher for F1 25 1.10.30 fixes a crash on **Continue** of a saved Grand Prix.

## Fixes

- **Continue** on a Grand Prix saved on a track whose addon is off or uninstalled no longer crashes the game on the loading screen. The weekend races Melbourne instead.

## Addon API

- `site_Car_RearWingRenderFraction` is a new experimental game binding in the addon headers (`swofty/game/car.hpp`, `game.rs`).

## Under the hood

- When the game looks up a track's data by a name no track record has, the core hands it the Melbourne record (else the first track's) instead of a null record. `loader.log` lines start with `[tracks] track data lookup guard:`. `SWOFTY_TRACK_LOOKUP_GUARD=0` turns it off.
