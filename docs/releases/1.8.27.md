# 1.8.27

Swofty Launcher for F1 25 1.8.27 puts the Addon Browser back the way it was in 1.8.21.

## Addon Browser

- The category rows are gone. The first page shows the categories, then **All addons** with every addon in one grid.
- Sorting is back on that page: **Stars**, **Downloads**, **Trending**, **Updated**, **Newest** and **Name** (and **Match** while searching).
- Select a category, search or use a filter to narrow the grid, as in 1.8.21.
