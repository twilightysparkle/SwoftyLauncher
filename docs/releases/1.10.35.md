# 1.10.35

Swofty Launcher for F1 25 1.10.35 fixes the career vault for careers an addon renames, dropped offline play downloads, freezes on slow drives and launcher saves on the EA app copy.

## Fixes

- Career saves: a career an addon renames at its first load (Progressive Career) is no longer reported missing, and the banner no longer offers a Restore that rolled the save back. False banners already showing clear at launcher start, and each Before restore version is labelled by why it was taken.
- Play no longer fails with "the download was blocked on this PC or network" when one offline play file's download drops. Each file is retried, and files already downloaded are kept for the next Play.
- The game no longer freezes for several seconds on slow or busy drives, in any mode. The launcher's files are no longer read from disk on the game's main thread.
- On the EA app copy, launcher saves load without the game's import prompt.
