# 1.8.13

Swofty Launcher for F1 25 1.8.13 lets shader effects give their own textures mip chains: smaller copies of the texture, each half the size of the one before, that a pass can sample at any level. Effects use them to average a whole picture in one read, for exposure and sky metering, and for cheap blurs.

## Shaders

- An effect texture can declare `"mips": N`, the number of levels including the full-size one, up to 12. After every pass that writes the texture, the launcher rebuilds the smaller levels from it, in game and in the Preview.

  ```json
  "textures": [
    { "name": "stats", "width": 64, "height": 32, "format": "rg16f", "mips": 7 }
  ]
  ```

- Passes read a level with `input_lod(i, uv, lod)` (filtered within and between levels), `input_lod_point(i, uv, lod)` (the nearest texel), and its size with `input_size_lod(i, lod)`. `input(i, uv)` keeps reading the full-size level. See [Shader configs and effects](/reference/addons/shaders).
