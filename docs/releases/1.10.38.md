# 1.10.38

Swofty Launcher for F1 25 1.10.38 keeps the first-start setup's text inside the window, and lets overlay addons react to wheel and joystick buttons.

## Fixes

- The first-start setup's text wraps inside the window at every window size. The ad privacy points no longer run off the right edge, and titles, notes and option cards wrap too. A step taller than the window scrolls, and **Back** and **Accept** stay in view.

## Standard library

- **Game controllers in overlays.** Overlay API version 6 gives every overlay addon the buttons of wheels, joysticks and other game controllers the game reads through DirectInput, such as a Logitech G920 under Proton, with `joy_held(n)`, `joy_hit(n)` and `any_pressed()`. Addons also get mouse clicks while no addon holds focus, so an addon can offer "press any button to skip". The game still gets every press. `SWOFTY_OVERLAY_KILL=joy` turns the controller reads off. See [Game controllers](/reference/std/overlay#game-controllers-v6).
